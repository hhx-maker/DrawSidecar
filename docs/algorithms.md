# Phase 2 算法说明

## 像素约定

原点位于左上角，x 向右，y 向下。RGBA 使用行优先 `Uint8ClampedArray`。二值障碍图使用 `Uint8Array`，0 表示可通行，1 表示障碍。Mask 使用 0 到 255，0 表示透明，255 表示完全选中。连通区域使用四连通，骨架邻域和端点识别使用八邻域。

## 预处理与骨架化

透明线稿模式只使用 Alpha 判断可见像素，因此透明像素中隐藏的 RGB 不会形成障碍。白底模式使用 sRGB 亮度阈值识别较暗笔画。Zhang–Suen 细化在固定最大迭代次数内执行，原图和原始 RGBA 数据保持不变。

## 缺口候选与虚拟闭合

骨架端点由八邻域计数识别。空间网格缩小候选搜索范围，再按端点距离和路径障碍计算启发式分数。分数用于排序和解释，不是概率。候选默认处于待确认状态。用户接受后才把直线桥接像素写入独立障碍图，原始线稿不变。

## 区域、智能选区与填色

可通行像素使用迭代四连通标记。边界可达区域单独标记为背景，代表点取实际遍历到的区域内像素。选区操作支持显式区域 ID、多选和限定作用域的反选。填色只生成独立全尺寸 RGBA 层，背景连接或异常区域默认给出警告。

## 整体底色

整体底色通过外部背景区域提取生成。内部镂空保持为透明。开放轮廓、多个边界背景或没有可达外部背景时返回警告，不能把整张画布直接当作前景。

## 已知局限

局部端点检查可能漏掉需要多个缺口共同闭合的复杂结构。几何区域不等于语义类别。当前桥接使用直线像素，不能重现原始笔刷纹理。复杂线稿仍需要用户审阅和手动修正。
